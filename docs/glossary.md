# Glossary (Ubiquitous Language)

- **Client**: Пользователь, пишущий боту @max_support_bot за помощью.
- **Assistant**: Оператор, отвечающий через Telegram-чат бота (или админский чат).
- **Ticket (Тикет)**: Сущность, объединяющая сообщения клиента и ассистента до решения проблемы.
- **Session (Сессия)**: Активное состояние переписки (mapping Client <-> Assistant).
- **Relay (Реле)**: Механизм пересылки сообщений между интерфейсами.
