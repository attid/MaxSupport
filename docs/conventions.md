# Конвенции разработки

## Python

- Python 3.13 и современные типы: `list[T]`, `T | None`, `StrEnum`, `UTC`.
- Асинхронный I/O на внешних границах; блокирующие операции не добавляются в
  event loop без явного обоснования.
- Файлы до 300 строк. Комментарии объясняют причину решения, а не пересказывают
  следующую строку.
- `ruff` определяет формат и стиль, `pyright` — типовые контракты.

## Границы

- Внешний JSON сначала проходит Pydantic validation.
- Domain/application не импортируют aiogram, httpx или SQLAlchemy.
- Адаптеры реализуют ABC-порты из `src/application/interfaces.py`.
- Composition root и управление ресурсами находятся только в `src/main.py`.

## Ошибки

- Ошибка одного MAX update не останавливает batch.
- Ожидаемые повреждённые payload логируются как warning и пропускаются.
- Сетевые ошибки логируют операцию, тип и статус без токенов или содержимого
  файлов.
- Широкий `except Exception` разрешён только на границе бесконечного фонового
  цикла или внешнего API, чтобы сохранить работу процесса.

## Тесты

- Баг начинается с падающего теста.
- Domain и application тестируются без сети.
- Infrastructure получает integration-тесты с временной SQLite или
  детерминированными HTTP doubles.
- Тесты времени используют явный UTC; тесты не зависят от текущего часа.

## Команды

- Перед коммитом: `just check`.
- Автоисправления: `just fmt`, затем повторно `just check`.
- Обновление зависимостей: изменить нижние границы, выполнить
  `uv lock --upgrade`, `uv sync --frozen` и полный набор проверок.
